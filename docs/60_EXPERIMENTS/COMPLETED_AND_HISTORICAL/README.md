# Completed and Historical Experiment Material

This folder contains completed reports, superseded runbooks, historical
programmes, retained non-passes and review material that are no longer the
current OTIS execution surface.

Placement here does not mean that every programme passed. Suspended,
superseded, rejected and incomplete work is retained because it remains part of
the scientific and engineering record. Read each artifact's own status and
terminal decision.

Historical evidence must still be interpreted with the source revision,
manifest, profile, schema and programme path recorded by the package that
created it. Moving tracked documentation into this folder is repository
organization; it does not rewrite old evidence identities or make current HEAD
a compatibility environment for historical campaigns.

The top-level `docs/60_EXPERIMENTS/` directory intentionally retains:

- the new descriptively named public-readiness programmes;
- the active state-preserving range-spanning programme; and
- older files or programme directories that remain exact hash-bound inputs to
  the current estimator, preview or continuation path.

Do not move those remaining bound inputs until their current consumers have
been deliberately superseded and the repository's active profiles no longer
resolve them by their existing paths.
