# CX323 sustained-hybrid successor study

This is an offline-only, prospectively frozen comparison prompted by the
Campaign18 Attempt 4 `prospective_repeated_alternation` terminal. It does not
change the frozen CX322/Campaign18 policy or evidence and creates no firmware,
flash, serial, DAC, control-arm, physical-run or live-activation authority.

The study preserves the unchanged acquisition and phase-material request path.
It compares only the `TIGHT_INSIDE`, phase-nonmaterial maintenance behavior:

1. the unchanged exact baseline;
2. two-window same-sign persistence plus a plant-envelope-derived
   no-zero-cross step cap, without correction debt; and
3. the same rule with bounded, provenance-bearing fractional maintenance debt.
