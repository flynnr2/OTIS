# Sustained-hybrid mode-separation architecture

## Decision served

This study asks whether OTIS can replace V1's single undifferentiated combined
controller with an explicit architecture that separates:

1. frequency acquisition outside the tight band;
2. phase-material correction while qualified raw relative-phase evidence is
   available; and
3. frequency-only maintenance after phase correction no longer changes the
   integer code request.

The deliverable is an offline architecture decision. It is not Attempt 5,
physical qualification, an activation, or authority to access the bench.

## Evidence-backed diagnosis

Attempt 4 reproduced 52 V1 decisions and the eleven natural applications

`-6,-1,-1,-6,-1,-1,-1,+5,+5,-5,+5`.

The first seven applications consumed 17 path codes and were phase-material:
including the phase term changed the prospective integer request relative to
the frequency-only request. The last four consumed 20 path codes but were
phase-nonmaterial: the integer request was unchanged by including the phase
term. They were generated by signed one-count 600-second estimates while
`TIGHT_INSIDE`.

The failed successor study suppressed the one-count frequency term whenever
tight. It therefore suppressed that term in the two early `-6` combined
requests as well as the late maintenance requests. Every candidate shared the
same early phase-preservation failure. This does not reject mode separation;
it rejects using tight-band membership alone as the mode discriminator.

The current selected estimator reports one count as `1/600 Hz`, declares an
empirical detection floor of approximately `2/600 Hz`, and declares calibrated
resolution and combined uncertainty unavailable. V1 nevertheless converts one
count to approximately 4.8075 raw codes. A one-count estimate is therefore
valid raw-derived evidence, but its sign and point magnitude are not sufficient
on their own to define efficient maintenance actuation.

## Architectural invariant

Every candidate first computes, from the same fresh causal observation:

- the frequency-only bounded integer request;
- the phase-only bounded integer request; and
- the V1 combined bounded integer request.

The decision is `PHASE_MATERIAL_CORRECTION` exactly when the combined integer
request differs from the frequency-only integer request. This classification
is computed before request submission and never depends on a response or later
plant observation. A candidate must preserve the full V1 combined law in this
mode. Otherwise the decision is `FREQUENCY_ONLY_MAINTENANCE`, in which the
candidate's separately declared maintenance policy applies.

Outside `TIGHT_INSIDE`, the V1 frequency-acquisition law remains authoritative
for every candidate. Identity, freshness, cadence, transaction, range, budget,
response, phase-epoch, and fail-static semantics remain unchanged.

## Frozen candidate architectures

### Phase-priority one-count maintenance hold

Preserve the full V1 combined request for every phase-material correction.
During frequency-only maintenance while tight, hold an absolute zero- or
one-count frequency contribution. Larger maintenance evidence remains enabled.

This is the smallest architecture change that tests whether causal command
classification, rather than tight-band membership, separates the observed
regimes.

### Separated FLL/PLL maintenance

Preserve the full V1 combined request for every phase-material correction.
During nonmaterial tight maintenance, suppress the frequency contribution and
allow only the independently rounded phase-only request. The frequency loop is
re-enabled by loss of tight-band residence under the existing two-window
release rule.

This is an explicit FLL/PLL arbitration architecture: frequency acquisition is
outside-band, phase correction has priority while it changes the command, and
the phase loop alone maintains the in-band code until frequency evidence
causes band release.

### Phase-priority 1200-second maintenance estimator

Preserve the full V1 combined request for every phase-material correction.
During frequency-only tight maintenance, replace the point 600-second
frequency input with the exact aggregate of two fresh, contiguous,
non-overlapping selected 600-second count outputs from the same capture
session and candidate DAC epoch. Hold until both supports exist. Reset on DAC
epoch, session, invalidity, stale support, settling exclusion, reference loss,
or authority loss.

This tests a distinct multi-support estimator architecture without a span
grid, fitted filter, guessed uncertainty, or overlapping decision evidence.

## Counterfactual model and uncertainty boundary

The exact claim ends at the retained V1 chronology. After a candidate requests
a different code, frequency and phase are modeled.

Differential candidate response is projected with the retained minimum,
nominal, and maximum observed `Hz/code` gains. Raw phase epochs are never
joined. Candidate applications use the exact retained decision coordinate and
all modeled values retain their provenance.

The earlier comparator added the full observed same-code repeatability span
and maximum hysteresis magnitude as a discontinuous frequency offset whenever
candidate and actual codes differed. The characterization evidence does not
identify that sum as the causal response of any nonzero code difference.
This study therefore does not reuse that projection.

Instead:

- the finite-run gain envelope bounds ordinary differential response;
- the observed 7.3493 equivalent-code hysteresis is exercised as an outward
  eight-code reversal dead-zone perturbation, not as a continuous offset;
- the one-count same-code spread is exercised as positive and negative
  maintenance-observation perturbations; and
- calibrated and combined uncertainty remain explicitly unavailable, so no
  selected offline architecture can inherit physical authority.

## Selection principle

The original phase, frequency, tight-occupancy, path-efficiency, reversal,
identity, and authority thresholds remain unchanged. In addition, a candidate
must reproduce the seven retained phase-material applications exactly through
the first maintenance frontier, classify modes causally, reset every
maintenance estimator state at the declared boundaries, and expose rather than
hide legitimate slow or reversing frequency demand.

No threshold, candidate, model rule, or ranking rule may be changed after the
comparison report is generated. A no-selection result is a valid terminal.
